# Word Raider with Python
This is a word-guessing game.<br>
Enter a 5-letter word.<br>
The application picks a random 5-letter word.<br>
If you guess correctly, you win!
## Overview
- The program picks a random 5-letter word.
- The player is given 5 turns to guess the word.
- After each try, the app provides feedback:<br>
  Correct letters in the right spot are displayed.<br>
  Right letters in the wrong spot are marked as misplaced.<br>
  Letters not in the word at all go into an incorrect list.
  
## Key Concepts
- Reading a list of words from an external text file (`five_letters_Bank.txt`).
- Using random module to select a secret mystery word.
- Implementing while and for loops alongside if/else conditional statements
- Managing user attempts, tracking correct/misplaced/incorrect letters with lists
